# Project

A React app built with Vite, using Chakra UI for components.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (with npm)

### Install dependencies

```bash
npm install
```

## Available Scripts

All scripts are run with `npm run <script>`:

| Script | Description |
| --- | --- |
| `npm run dev` | Start the Vite development server with HMR (logs are also written to `vite.log`) |
| `npm run build` | Create an optimized production build in `dist/` |
| `npm run preview` | Serve the production build locally to test it before deployment |
| `npm run lint` | Run ESLint over the project source |
| `npm run clean` | Remove build artifacts (`dist/`) and installed dependencies (`node_modules/`) |

## Typical workflow

```bash
npm install      # one-time setup
npm run dev      # develop locally at http://localhost:5173
npm run build    # production build
npm run preview  # test the production build locally
```
